---
title: Motherload
description: Import a TOML, YAML, JSONC, JSON5, CSV, TSV, Markdown, text or .env file and get a typed module.
---

Motherload is a set of TypeScript loaders for data formats: import a TOML, YAML, JSONC, JSON5, CSV, TSV, Markdown, text or `.env` file and get a typed module.

It's powered by TypeScript's [_content mappers_](https://github.com/microsoft/typescript-go/pull/4712) (introduced typescript@7.1). These are like plugins for TypeScript, and it lets Motherload provide _full static types_ for the imported data, in a way that natively integrates with `tsc`.

```ts twoslash tab="main.ts"
import plans from "./plans.toml";
import team from "./team.yaml";
import strings from "./strings.json5";
import posts from "./posts.csv";
import notes from "./notes.md";
import "./.env";
```

```toml tab="plans.toml"
[free]
price = 0
seats = 1

[pro]
price = 12
seats = 10
```

```yaml tab="team.yaml"
- name: Ada
  role: admin
- name: Grace
  role: member
```

```json5 tab="strings.json5"
{
  // shown on the sign-in page
  welcome: 'Welcome back',
  signIn: 'Sign in',
}
```

```csv tab="posts.csv"
slug,title,published
hello,Hello world,2026-10-01
loaders,Loaders,2026-10-06
```

```md tab="notes.md"
---
title: Release notes
tags: [beta]
---
The first beta.
```

```sh tab=".env"
DATABASE_URL=postgres://localhost/app
```

Hover over an import to see its type. Each type comes from the file, in the type check and in the editor, and the same imports run under Node.js, Nub and esbuild.
